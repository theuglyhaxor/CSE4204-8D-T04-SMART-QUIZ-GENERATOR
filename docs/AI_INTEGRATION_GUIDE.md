# Gemini AI Integration Guide

## Goal

This backend already contains a Gemini-powered quiz generation flow. The next step is to configure the backend key and validate the endpoint end to end.

## How the AI flow works

1. The frontend sends generation details to `POST /api/ai/generate-quiz/`.
2. The backend reads the request data and calls Gemini from the server.
3. The backend validates the Gemini response.
4. The backend creates a `Quiz` row and linked `Question` rows.
5. The backend returns the newly created quiz and generated questions.

## Current backend implementation details

The backend currently:

- Builds a Gemini prompt in `backend/quiz_api/services.py`
- Calls Gemini through `urllib` with the configured API key
- Parses the Gemini response as JSON
- Validates the structure and question fields
- Creates the quiz and questions in the database
- Returns the generated data as JSON

### Access control

The AI generation endpoint is **teacher-only** and requires a valid token from `/api/auth/login/`.

## Required environment variables

Add these variables to your backend environment:

- `GEMINI_API_KEY`
- `GEMINI_MODEL` (optional, defaults to `gemini-1.5-flash`)
- `GEMINI_TIMEOUT` (optional, defaults to `30`)

## How to configure Gemini on Windows

```powershell
$env:GEMINI_API_KEY = "your-api-key"
$env:GEMINI_MODEL = "gemini-1.5-flash"
$env:GEMINI_TIMEOUT = "30"
```

If you are using a `.env` file, make sure your process reads it before Django starts. The current backend reads environment variables directly from `os.environ`.

## Request format

### POST /api/ai/generate-quiz/

```json
{
  "title": "Biology Quiz",
  "difficulty": "Medium",
  "question_count": 5,
  "topic": "Cell structure and function",
  "syllabus": "Describe mitochondria, nucleus, ribosome, and cell membrane.",
  "instruction": "Generate only multiple-choice questions with four options and one correct answer.",
  "duration_minutes": 8
}
```

## Prompt design rules

The backend prompt currently asks Gemini to return structured JSON. Follow these rules for better output quality:

- Include the topic and difficulty.
- Set a concrete question count.
- Require exactly four options.
- Require exactly one correct answer.
- Require a short explanation.
- Avoid duplicate concepts.
- Prefer clear and simple language.

### Example prompt

```text
Generate 5 multiple-choice quiz questions about: cell structure and function.
Difficulty: Medium.

Additional syllabus context:
Mitochondria, nucleus, ribosome, and cell membrane.

Instructions:
- Use only multiple-choice questions.
- Exactly 4 options per question.
- Exactly one correct answer.
- Include a short explanation for the correct answer.
- Return valid JSON only.
- Do not include markdown fences.
```

## Validation rules

The backend validates Gemini output before saving data:

- The response must be valid JSON.
- The payload must include a non-empty `title`.
- The payload must contain a non-empty `questions` array.
- Each question must contain `prompt`, `option_a`, `option_b`, `option_c`, `option_d`, `correct_option`, and `explanation`.
- `correct_option` must be one of `A`, `B`, `C`, or `D`.
- The number of returned questions must be at least the requested count.

## How to test Gemini integration

### 1. Set the API key

```powershell
$env:GEMINI_API_KEY = "your-api-key"
```

### 2. Restart the backend

```powershell
cd backend
python manage.py runserver 8001
```

### 3. Call the AI endpoint

```powershell
$body = '{"title":"AI Test Quiz","difficulty":"Medium","question_count":2,"topic":"Science","syllabus":"Cells and planets","instruction":"Generate two clear MCQs.","duration_minutes":5}'
Invoke-WebRequest -Method POST -ContentType "application/json" -Body $body http://127.0.0.1:8001/api/ai/generate-quiz/ | Select-Object -ExpandProperty Content
```

### 4. Confirm the result

A successful response should:

- return `201 Created`
- include a new `quiz` object
- include a `questions` array
- persist the generated records in MySQL

## Recommended improvements

If you want to harden AI generation, add:

- retry logic for transient API failures
- request rate limiting
- prompt audit logging
- caching for repeated generation requests
- stricter prompt templates for quiz quality

## Security and cost control

- Keep the Gemini API key only on the backend.
- Do not expose the key to the frontend.
- Limit the request size and question count.
- Use environment variables for all secrets.
- Avoid logging the full prompt or API key.

## Important note for the frontend team

The frontend must not call Gemini directly. All AI generation must go through the backend so the API key stays private and output parsing stays consistent.
